# Specs

Une fonctionnalité = un dossier `NNN-slug/` :

- `spec.md` — le QUOI : user stories, critères d'acceptation `AC-n`, cas limites. Créé par `/devflow:spec`.
- `plan.md` — le COMMENT : architecture, modèle de données, contrats d'API, découpage en tâches. Créé par `/devflow:plan`.

Statuts : spec `Brouillon → Validée → Livrée`, plan `Brouillon → Approuvé → Livré`.
Les issues GitHub ne sont créées qu'une fois le plan approuvé.
