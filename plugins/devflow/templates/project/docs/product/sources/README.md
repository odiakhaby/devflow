# Sources brutes

Dépose ici tout ce qui vient du client ou de la phase de cadrage : comptes-rendus de réunion, mails, cahier des charges, maquettes, captures, notes vocales transcrites.

`/devflow:discover` lit ce dossier en premier et ne te pose que les questions auxquelles ces documents ne répondent pas.
Ne mets pas de secrets ni de données personnelles réelles ici : le dossier est versionné.
